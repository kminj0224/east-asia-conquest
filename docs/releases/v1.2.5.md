# 동아시아 콘퀘스트 v1.2.5

- 일본 유탄수(type 8), 대전차보병(type 9), 중기관총병(type 10)에 첨부 이미지 1~5를 연결했습니다. 유탄수와 대전차보병은 대기/공격 자세를 전환하고, 중기관총반은 왼쪽을 향한 공용 이미지로 연사합니다.
- 일본 소총수의 대기/공격 이미지를 첨부 이미지 6~7로 교체했습니다.
- 원본 WebP 4개와 PNG 3개를 파일 그대로 포함합니다. Base64/data URL, 이미지 재인코딩, 리사이즈, 배경 합성은 사용하지 않습니다. manifest에 원본 SHA-256 및 투명도 경계를 기록합니다.
- 원본 비율을 유지하며, 좌우 반전·총구 섬광·유탄 궤적·대전차 발사 연기·연사·효과음·피격 위치를 기존 렌더러에 연결합니다.
- v1.2.4의 전차 크기와 지도 경계, 다른 국가 및 게임 규칙은 유지합니다.
- 앱 ID와 서명 인증서를 유지하는 업데이트 APK입니다. 버전 1.2.5, Android versionCode 10.

# 동아시아 콘퀘스트 v1.2.6 — 현대 도시·수도 랜드마크

- 선택한 1안의 정교한 반실사 일러스트로 모든 도시 외형을 교체했습니다. 일반 도시는 국가 공통 1~5레벨로 구분하며, 레벨이 높을수록 건물 밀도·고층 실루엣·표시 크기가 커집니다.
- 수도 6종은 모두 레벨5급 고층 대도시에 상징 랜드마크를 하나 더한 모습입니다. 서울 광화문, 베이징 자금성, 도쿄 도쿄타워, 평양 주체사상탑, 타이베이 타이베이101, 블라디보스토크 금각교를 적용했습니다.
- 베이징은 천단 대신 자금성을 사용합니다. 러시아의 게임 내 수도 블라디보스토크는 그대로 유지합니다.
- 수도 외형은 실제 도시 레벨과 별개이며, 점령돼도 도시의 원래 랜드마크를 유지합니다. 도시 등급·이름·내구도·생산·공항·방어시설·화재·선택과 저장 규칙은 유지합니다.
- 원본 투명 PNG 아틀라스 3개를 파일로 포함합니다. PNG Base64/data URL, 픽셀 재인코딩, 런타임 이미지 스캔을 사용하지 않습니다. 오프라인 경계값으로 원본 이미지 일부를 직접 그립니다.
- v1.2.5 일본 보병 이미지 및 기존 전차 배율·지도·게임 규칙을 유지합니다.
- 버전 1.2.6, Android versionCode 11. 기존 앱 ID와 서명 인증서를 유지하는 업데이트 APK입니다.

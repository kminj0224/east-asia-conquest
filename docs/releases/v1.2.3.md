# 동아시아 콘퀘스트 v1.2.3

- 한국군 일반 전차(type 1)의 표시 가로·세로 크기를 기존의 90%로 조정했습니다. 경전차·정예전차 및 다른 나라 전차의 크기는 유지합니다. 포신, 발사 섬광, 피격 위치와 그림자는 같은 축소 배치를 사용하며 PNG 원본은 수정하지 않습니다.
- 지도 본체 99×122칸 밖의 추가 바다 7,048칸을 제거했습니다. 기존 육지 3,672칸과 도시 148개는 그대로입니다.
- 좌우 순환, 경계 너머 이동과 사격 거리 단축을 제거했습니다. 지도 사각형이 세계의 끝입니다.
- 화면 비율에 맞춰 최대 축소를 제한하고 카메라의 네 가장자리를 지도 안에 유지합니다. 드래그·핀치·휠·확대축소 버튼·미니맵·화면 회전·저장 복원에도 적용합니다.
- 기존 확장 바다 지도의 저장을 읽을 수 있습니다. 삭제된 외곽 바다에 있던 부대는 불러오기에서 제외됩니다.
- 앱 버전 1.2.3, Android versionCode 8. 기존 앱 ID와 서명 인증서를 유지합니다.

## 실행

GitHub Actions의 `한국군 전차·지도 경계 v1.2.3 — 메인 반영 및 릴리스`에서 `main`을 선택하고 `Run workflow`를 한 번 실행합니다. 별도 입력은 없습니다.

워크플로는 고정된 준비 커밋을 가져와 main과 합친 후보 커밋을 만들고, 원본 PNG SHA-256·게임 회귀검사·실제 Chromium·지도 아틀라스·네이티브 셸·APK 버전/서명/포함 파일을 검증한 뒤 그 커밋을 main에 push하고 같은 커밋을 v1.2.3으로 릴리스합니다. 검사 또는 빌드 실패 시 main push와 릴리스 단계에 도달하지 않습니다. 기존 v1.2.3 태그나 릴리스가 있으면 덮어쓰지 않고 중단합니다.

이번 대화에 새로운 PNG 첨부는 전달되지 않았습니다. 준비 브랜치는 기존에 등록된 한국군 전차 원본 PNG(`eastasia-kr-tank.png`, SHA-256 `33a598a486a810fdee5dcfc7cbd35690858994f92d74d6411f8d68a9a40bc3cd`)를 그대로 포함합니다. 새로운 이미지로 교체하거나 재인코딩하지 않습니다.

## 준비 단계 검증

로컬에서 npm test 전체, 432가지 카메라 경계, 전차 96상태, 지원보병 24상태, 원본 PNG SHA-256, 48개 아틀라스, 네이티브 셸, 서명 APK 빌드 및 APK 버전/포함 자산 검사를 통과했습니다. 로컬 Chromium 프로세스는 실행 환경에서 SIGTRAP으로 종료되어 실제 브라우저 검사는 완료하지 못했습니다. 수동 워크플로는 Ubuntu에서 Chromium을 설치하여 이 검사를 필수 실행하고, 실패하면 main 반영과 릴리스를 중단합니다.

## 수동 실행 실패 수정

첫 실행은 Android 30 FPS 환경의 극단적 드래그 경계 검사에서 중단되었습니다. 카메라 경계를 다음 그리기까지 기다리지 않고 드래그·핀치·휠·확대축소 버튼·화면 크기 변경·수도/다음 부대 이동 시 즉시 적용합니다. 프레임을 생략하는 경로에서도 먼저 경계를 적용합니다. 회귀검사는 입력 직후와 프레임 생략 시점을 검사하며, 브라우저 검사에서 화면 크기 변경 이벤트 완료를 확인하고 실패 시 카메라 수치를 출력합니다. 버전은 아직 릴리스되지 않은 1.2.3을 유지합니다.

# v1.2.2 — 한국군 지원보병 이미지

대한민국 유탄수(type 8), 대전차보병(type 9), 중기관총병(type 10)에 사용자 원본 PNG를 연결했습니다. 유탄수와 대전차보병은 대기/공격 자세를 전환하고 중기관총반은 공용 이미지로 연사합니다. 방향 전환, 유탄 궤적, 대전차 발사 연기, 총구 섬광, 기존 효과음과 피격 효과를 유지합니다. 중기관총 이미지는 원본이 왼쪽을 바라보므로 별도의 기본 방향을 적용합니다.

PNG는 파일 그대로 읽고 APK에 바이트 그대로 포함합니다. Base64, data URL, 이미지 재인코딩, 리사이즈, 배경 합성은 사용하지 않습니다. 기존 한국/일본 소총수·전차와 다른 국가의 외형은 유지합니다.

## 직접 업로드와 수동 반영

아래 5개 파일을 이름만 바꾸어 **이 PR의 작업 브랜치** `game/assets/`에 푸시합니다. GitHub 웹에서는 해당 브랜치의 폴더를 연 뒤 Add file → Upload files로 올릴 수 있습니다.

| 첨부 원본 | 저장소 파일명 | 역할 |
|---|---|---|
| 1000068391.png | eastasia-kr-antitank-idle.png | 대전차보병 대기 |
| 1000068392.png | eastasia-kr-antitank-fire.png | 대전차보병 공격 |
| 1000068387.png | eastasia-kr-grenadier-idle.png | 유탄수 대기 |
| 1000068388.png | eastasia-kr-grenadier-fire.png | 유탄수 공격 |
| 1000068390.png | eastasia-kr-machinegun.png | 중기관총반 공용 |

1. PNG 5개를 PR 브랜치에 푸시합니다. 파일 이름만 변경하고 이미지 내용은 변경하지 않습니다.
2. PR의 **Merge pull request** 버튼으로 main에 반영합니다.
3. **Actions → Manual APK release → Run workflow → Branch: main → Run workflow**를 누릅니다.
4. 원본 SHA-256/크기 확인, 게임 회귀검사, 실제 Chromium 검증, 네이티브 검사, 서명 APK 검증이 모두 성공하면 v1.2.2 릴리스를 게시합니다.

푸시와 병합만으로 릴리스는 실행되지 않습니다. 작업은 소스나 PNG를 main에 자동 커밋하지 않습니다. 검증 실패 시 릴리스를 게시하지 않으며 Actions의 검사 산출물을 확인할 수 있습니다. 동일한 v1.2.2 태그가 이미 있으면 덮어쓰지 않고 실패합니다.

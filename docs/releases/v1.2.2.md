# v1.2.2 — 한국군 지원보병 이미지

대한민국 유탄수(type 8), 대전차보병(type 9), 중기관총병(type 10)에 사용자 원본 PNG를 연결했습니다. 유탄수와 대전차보병은 대기/공격 자세를 전환하고 중기관총반은 공용 이미지로 연사합니다. 방향 전환, 유탄 궤적, 대전차 발사 연기, 총구 섬광, 기존 효과음과 피격 효과를 유지합니다. 중기관총 이미지는 원본이 왼쪽을 바라보므로 별도의 기본 방향을 적용합니다.

PNG는 파일 그대로 읽고 APK에 바이트 그대로 포함합니다. Base64, data URL, 이미지 재인코딩, 리사이즈, 배경 합성은 사용하지 않습니다. 기존 한국/일본 소총수·전차와 다른 국가의 외형은 유지합니다.

## 버튼 한 번으로 메인 반영과 릴리스

코드와 원본 PNG 5개는 준비 브랜치에 모두 들어 있습니다. 파일 업로드, Git 명령, PR 수동 병합은 필요하지 않습니다.

GitHub Actions에서 **한국군 지원보병 v1.2.2 — 메인 반영 및 릴리스 → Run workflow → Branch: main → Run workflow**를 누릅니다.

작업은 고정된 준비 커밋을 임시로 병합하고, 원본 SHA-256/크기 확인, 게임 회귀검사, 실제 Chromium 검증, 네이티브 검사, 서명 APK 검증을 실행합니다. 모두 통과하면 main에 병합 커밋을 푸시하고 그 커밋을 대상으로 v1.2.2 릴리스를 게시합니다. PNG는 원본 파일 그대로 유지합니다.

작업 등록만으로 게임 변경 사항을 main에 반영하거나 APK를 게시하지 않습니다. 사용자의 수동 실행이 있어야 진행합니다. 검사 실패 시 main에 푸시하지 않습니다. 검사 도중 main이 변경되어 푸시가 거부되면 릴리스도 게시하지 않습니다. 이미 게시된 v1.2.2 릴리스는 덮어쓰지 않습니다.
